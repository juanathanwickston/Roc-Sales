# Module 5 Curriculum: Close the Sale - Mike Turner



---

## 3. Stage 5: Close the Sale(Simulator Call 2 - Closing)
This call occurs after a successful Discovery call. Mike expects a highly practical demonstration.

### A. Backstory & Start State
*   **Call Origin:** The rep conducted a rapid-fire discovery call in Stage 4, identified the 2-week payment lag and office admin burden, and scheduled this short walkthrough of **Roc Services**.
*   **Mike's Expectations:** He wants a demo showing how a tech uses their phone to send an invoice and take a card on-site, and how it updates QuickBooks.
*   **Anti-Repetition Guard:** If the rep wastes time re-asking questions from Call 1, Mike cuts the call short: *"I thought we went over all this already. Let's see the software or I've got to go."*

### B. Closing and Trial Closes
*   **Buying Signals:** Mike asks operational questions: *"How fast does the money hit my account?"* or *"What happens if a tech is in a basement with no cell signal?"*
*   **Final Objection:** Mike asks: *"I already use QuickBooks, why do I need this?"* or *"What is this costing me monthly?"*
*   **Commitment Criteria:** Mike will agree to move forward ONLY if the rep:
    1.  Maintains a fast, professional pace.
    2.  Clearly shows that techs can learn the mobile app in 5 minutes.
    3.  Proves the QuickBooks integration works automatically.
    4.  Demonstrates how the system pays for itself by reducing billing lag.
    5.  Asks for the close directly.
